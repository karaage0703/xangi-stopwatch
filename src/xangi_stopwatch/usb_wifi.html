StopWatchのWi-Fi設定

初めての登録も、接続できなくなったときも、この画面で設定できます。

このPCとStopWatchをデータ通信対応のUSBケーブルでつないでください。

USB接続待ちです。PC版Chrome・Edgeで開いてください。

USB設定を利用できません。PC版Chrome・EdgeでこのHTMLを直接開くか、PC上のxangi-stopwatchソースのフォルダで uv run xangi-stopwatch-wifi を実行して表示されたlocalhostのURLを開いてください。

接続するWi-Fi

2.4GHzのみ対応。SSIDは32バイト以内です。

認証なしのWi-Fiは空欄。それ以外は8〜63バイト。同じSSIDならパスワードを更新します。

保存すると本体が再起動します。接続に失敗しても、この画面から設定し直せます。パスワードはUSBで本体へ送り、サーバーやブラウザには保存しません。

保存したWi-Fi

初期設定・選択中のWi-Fiは削除できません。保存は5件までです。

初回はUSB設定対応のTailnetファームを書き込んでおく必要があります。Tailscale登録キーとサーバー接続先はファーム作成時に設定します。
